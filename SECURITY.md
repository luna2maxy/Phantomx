# Security Policy

> **NOTE (PoI+Verifier removed):** PhantomX consensus/finality has moved to **PoI + Verifier attestation**. Any remaining PoI+Verifier/verifier wording in this document is historical and must not be used to reintroduce PoI+Verifier.


## Status
Foundation. No mainnet security claim. Do not report this project as production-ready.

## Reporting
- Do not publish exploit details before a fix is available.
- Provide reproduction steps, affected components, impact assessment, and suggested mitigation.

## Security Scope
Consensus/PoI+Verifier, PoI evidence/verification, aggregator certificates, UTXO/tx validation, P2P/RPC, wallet/key handling, rewards/accounting, DB recovery.

## Current Limitations
See `docs/KNOWN_LIMITATIONS.md` and `docs/THREAT_MODEL.md`.
