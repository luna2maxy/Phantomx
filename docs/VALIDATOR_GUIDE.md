# PhantomX Verifier Guide (Foundation)

> **NOTE (PoI+Verifier removed):** PhantomX consensus/finality has moved to **PoI + Verifier attestation**. Any remaining PoI+Verifier/verifier wording in this document is historical and must not be used to reintroduce PoI+Verifier.


Foundation draft. PoI+Verifier verifier operations are not production-hardened. Requires full verifier key management, slashing/equivocation policy, monitoring, and finality-safe operations before any public network.
